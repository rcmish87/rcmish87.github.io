Important

Download a full JSON backup before changing browsers, clearing site data or importing a database. JSON backup includes all records and settings stored by this app.

SQLite on Android: this browser-based app keeps its active working copy in browser storage. SQLite import/export transfers a database file; it does not continuously write changes back into the original file you selected. The first SQLite feature use may require internet to load the SQLite engine.

Privacy & usage

  • Records are stored locally in this browser on this device.
  • There is no account login, cloud sync or automatic bank connection.
  • Never share your backup file publicly; it contains personal financial information.
  • Keep multiple backups in a secure location. Browser storage is not a substitute for backup.
  • Amounts and asset valuations are entered by you; no live market prices are fetched.
